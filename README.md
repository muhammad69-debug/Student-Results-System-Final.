# نظام إدارة نتائج الطلاب | Student Results Management System

## تشغيل المشروع
1. فك ضغط مجلد المشروع بالكامل.
2. افتح `index.html` باستخدام متصفح حديث مثل Google Chrome أو Microsoft Edge.
3. يلزم الاتصال بالإنترنت لتحميل Bootstrap وخط Cairo من CDN.

## هيكل المشروع
```text
Student-Results-System/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── main.js
```

## الوظائف المنفذة
- إضافة طالب مع ثلاث درجات ونسبة حضور.
- استخدام الكلاس `Student` والحقول الخاصة `#` مع Getters وSetters.
- التحقق من الاسم والدرجات والحضور، وإظهار الأخطاء للمستخدم باستخدام `try/catch`.
- عرض قائمة الطلاب ومتوسط درجات كل طالب.
- استخدام `filter` لاختيار الطلاب الذين متوسطهم من 40 إلى 49.
- استخدام `map` لإضافة خمس درجات رأفة إلى متوسط كل طالب مستحق.
- استخدام `reduce` لحساب المتوسط العام بعد الرأفة، مع معالجة حالة عدم وجود طلاب مستحقين.

## ملاحظة
بيانات الطلاب محفوظة في المصفوفة أثناء تشغيل الصفحة فقط، ولا تُخزَّن بعد تحديث الصفحة؛ التخزين الدائم غير مطلوب ضمن تعليمات التكليف المرفقة.
